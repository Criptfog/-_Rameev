                                                Dnevnik Rameev 

**- Мобильное приложение и электронный дневник для студентов Цифрового колледжа им. Башира Рамеева. Программа объединяет расписание занятий, списки задач и учебный профиль в едином минималистичном интерфейсе.
-Основные возможностиРасписание (ScheduleView): Просмотр учебных пар и актуального расписания на каждый день.   
Задачи (TasksView):
-Учет домашних заданий, дедлайнов и текущих учебных задач.   
-Дневник (DiaryView): Отслеживание оценок и мониторинг успеваемости.   
-Профиль (ProfileView): Отображение личных данных студента.   
-Авторизация и синхронизация (LoginView, SyncBanner): Быстрый вход в систему и обновление актуальных данных через учебный портал.  
-Технологический стекФреймворк: Capacitor (кросс-платформенная сборка под Android)**   
                          
                          Интерфейс: Современные веб-компоненты и адаптивная верстка
